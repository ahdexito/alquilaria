CÓDIGO FUENTE EN JAVA

Desarrollo de la aplicación que interactúa con la base de datos

Aquí se presentan ejemplos clave del código Java que da vida a la aplicación Alquilaria, mostrando la organización, la lógica de negocio y la interacción con la base de datos.

Estructura General del Proyecto (NetBeans)

Esta captura de pantalla de NetBeans proporciona una vista rápida de la estructura del proyecto Alquilaria y la cantidad total de clases que lo componen, reflejando su modularidad y organización.


Clase Contrato

La clase Contrato es el objeto principal que define la estructura de un contrato de alquiler en la aplicación. Contiene atributos como ID de contrato, fechas, renta mensual, y su estado, encapsulando la lógica de negocio de cada contrato.


Clase InterfazContrato

La clase InterfazContrato es la responsable de la representación visual de la gestión de contratos. A continuación, se muestran diferentes aspectos de su funcionalidad y diseño, como la entrada de datos, la visualización de contratos y las opciones de edición.


Clase ContratoCRUD

La clase ContratoCRUD maneja las operaciones de Creación, Lectura, Actualización y Borrado (CRUD) para los objetos 'Contrato' en la base de datos. Se encarga de la interacción directa con la capa de persistencia, asegurando la integridad de los datos.


Clase Menú

La clase Menú actúa como el controlador central de la aplicación. Orquesta las llamadas a las diferentes interfaces de usuario y a las clases de lógica de negocio (como 'ContratoCRUD'), gestionando el flujo de la aplicación y la interacción con el usuario.
