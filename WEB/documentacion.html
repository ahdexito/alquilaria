Diagrama de clases, diagrama de casos de uso, diagrama de secuencia, y Javadoc

Aquí encontrarás una visión técnica detallada de la arquitectura y el funcionamiento interno de la aplicación Alquilaria, presentada a través de diagramas clave.

Diagrama de Clases

Este diagrama UML muestra la estructura estática del sistema, las clases principales de Alquilaria, sus atributos, métodos y las relaciones entre ellas. Refleja cómo la aplicación gestiona entidades como Propietario, Inquilino, Vivienda y Contrato.

Diagrama de Casos de Uso

Representa las funcionalidades principales de Alquilaria desde la perspectiva del usuario. Describe cómo los actores (por ejemplo, el "Administrador de Propiedades") interactúan con el sistema para realizar tareas como Consultar Viviendas, Modificar Contratos o Crear Propietarios.

Diagrama de Secuencia

Ilustra la interacción entre los objetos de Alquilaria en una secuencia temporal para una función específica, como Exportar Datos de Estadísticas. Muestra el orden de los mensajes pasados entre los objetos para completar una tarea.
