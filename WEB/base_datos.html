BASE DE DATOS

Diagrama entidad-relación, modelo lógico, diseño físico

A continuación, se detalla la estructura de la base de datos de Alquilaria, mostrando cómo se organizan y relacionan los datos de la aplicación.

Diagrama Entidad-Relación (DER)

Este diagrama conceptual representa las entidades principales de la aplicación (como Propietario, Inquilino, Vivienda y Contrato) y las relaciones entre ellas. Muestra la lógica de los datos sin entrar en detalles de implementación de la base de datos específica.

Diagrama de Diseño Lógico

Aquí se visualiza la estructura de la base de datos a nivel de tabla, incluyendo las tablas, sus columnas (atributos), tipos de datos, claves primarias y foráneas. Es un paso intermedio entre el DER y el script de creación.
